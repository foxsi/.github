## About FOXSI

The Focussing Optics X-ray Solar Imager (FOXSI) rocket is an X-ray instrument optimised for lookin at the Sun.

Visit our Github website [here](https://foxsi.github.io/) at `https://foxsi.github.io/`.

More information on the 4th and 5th iteration of the rocket can be found here:
- 🔭 [FOXSI-4 and -5](https://foxsi.umn.edu/) sounding rockets.

### Repository links

The FOXSI Github has a number of repositories so here is a top-level directory for some active useful ones.

**Public**

- FOXSI response tools
  - The ``response-tools`` repository.
  - The code lives [here](https://github.com/foxsi/response-tools) and there is an [accompanying website](https://foxsi.github.io/response-tools/index.html) containing FOXSI-4 flight and instrument information.
- FOXSI science code and tools
  -  The ``foxsi4-science-tools`` repository.
  -  The code is [here](https://github.com/foxsi/foxsi4-science-tools) and contains different examples and scripts in different languages for working with FOXSI-4 and -5 data.

**Private**

- FOXSI-4/5 CdTe detectors
  - The ``cdte-tools`` repository.
  - The code is [here](https://github.com/foxsi/cdte-tools) and contains a bunch of code to run the calibration steps for the CdTe detector data.
  - Contains calibration code and code examples to work with the data.
- FOXSI-4/5 CMOS detectors
  - The ``cmos-tools`` repository.
  - The code is [here](https://github.com/foxsi/cmos-tools) and contains the processed files from the CMOS calibration.
  - Examples and code exists here on how to work with the calibrated files.
